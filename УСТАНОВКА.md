# sCalp — полная установка из архива (Termix / Linux)

Копируй команды **по блокам**. Цель: скачать → распаковать → установить → открыть в браузере без ручной возни.

Порт по умолчанию: **4173**  
Нужно: `python3`, `curl`, `unzip` (или `tar`). Для React ещё `node`/`npm` — для стакана **не обязательны**.

---

## 0) Один раз: инструменты

### Linux (Fedora / Ubuntu через Termix SSH)

```bash
# Fedora
sudo dnf install -y python3 curl unzip

# Ubuntu / Debian
# sudo apt update && sudo apt install -y python3 curl unzip
```

### Termux (Android, если ставишь прямо на телефон)

```bash
pkg update -y
pkg install -y python curl unzip
```

Проверка:

```bash
python3 --version
curl --version | head -1
unzip -v | head -1
```

## 1) Скачать архив

Положи zip в `~/Downloads` (или скачай командой).

### Вариант A — уже есть файл на этой машине

```bash
ls -lah ~/Downloads/SCALP.zip ~/SCALP/SCALP.zip 2>/dev/null
```

### Вариант B — скачать по URL (подставь свою ссылку)

```bash
mkdir -p ~/Downloads
cd ~/Downloads
curl -L -o SCALP.zip "https://EXAMPLE.com/SCALP.zip"
# или: wget -O SCALP.zip "https://EXAMPLE.com/SCALP.zip"
```

### Вариант C — скопировать с ПК по SCP (с компьютера)

```bash
scp ./SCALP.zip user@IP_СЕРВЕРА:~/Downloads/SCALP.zip
```

### Вариант D — сделать свежий архив из текущей папки (на машине, где уже есть проект)

```bash
cd ~
rm -f ~/Downloads/SCALP.zip
cd .
zip -r ~/Downloads/SCALP.zip . \
  -x "node_modules/*" \
  -x ".git/*" \
  -x "dist/*" \
  -x ".scalp-server.*" \
  -x "*.log" \
  -x ".venv/*" \
  -x "venv/*"
ls -lah ~/Downloads/SCALP.zip
```

---

## 2) Распаковать

```bash
mkdir -p ~/apps
cd ~/apps
rm -rf SCALP
unzip -o ~/Downloads/SCALP.zip -d SCALP
# если архив уже содержит папку SCALP/ внутри — смотри ниже «Если вложено»

cd ~/apps/SCALP
# если после unzip файлы лежат в ~/apps/SCALP/SCALP/ — сдвинь:
# shopt -s dotglob && mv SCALP/* . && rmdir SCALP

ls ЗАПУСК.sh install.sh local/serve.py
```

Альтернатива, если архив `.tar.gz`:

```bash
mkdir -p ~/apps && cd ~/apps
tar -xzf ~/Downloads/SCALP.tar.gz
cd SCALP
```

---

## 3) Установить одной командой

```bash
cd ~/apps/SCALP   # или cd ~/SCALP — куда распаковал
chmod +x install.sh ЗАПУСК.sh СТОП.sh open.sh
./install.sh
```

Скрипт:
- выставит права на скрипты;
- поправит пути в `.desktop`;
- проверит `python3` / `curl`;
- сразу запустит сервер (`./ЗАПУСК.sh`).

Только поставить **без** автозапуска:

```bash
SCALP_AUTOSTART=0 ./install.sh
./ЗАПУСК.sh
```

С установкой React/Vite:

```bash
SCALP_WITH_REACT=1 SCALP_AUTOSTART=0 ./install.sh
```

---

## 4) Открыть

На **той же машине**:

- http://127.0.0.1:4173/ — панель  
- http://127.0.0.1:4173/local/ — терминал  
- http://127.0.0.1:4173/docs/ — документация  

С **телефона** (Termix → сервер в LAN): подставь IP сервера:

```bash
hostname -I | awk '{print $1}'
# пример: http://192.168.1.42:4173/
```

Остановка:

```bash
./СТОП.sh
```

Повторный старт:

```bash
./ЗАПУСК.sh
```

## 5) Всё одной простынёй (копипаст)

Подставь путь к zip, если он другой.

```bash
sudo dnf install -y python3 curl unzip   # Fedora; на Ubuntu — apt, см. блок 0

mkdir -p ~/Downloads ~/apps
# если zip ещё нет — сначала блок 1 (скачать / zip / scp)

cd ~/apps
rm -rf SCALP
unzip -o ~/Downloads/SCALP.zip -d SCALP
cd ~/apps/SCALP
# на случай вложенной папки:
if [[ ! -f ЗАПУСК.sh && -f SCALP/ЗАПУСК.sh ]]; then shopt -s dotglob; mv SCALP/* .; rmdir SCALP; fi

chmod +x install.sh ЗАПУСК.sh СТОП.sh open.sh
./install.sh
```

## Если что-то пошло не так

| Симптом | Что сделать |
|---------|-------------|
| `unzip: command not found` | `sudo dnf install unzip` / `pkg install unzip` |
| `Permission denied: ./install.sh` | `chmod +x install.sh ЗАПУСК.sh` |
| Порт занят | `./СТОП.sh` или `SCALP_PORT=4174 ./ЗАПУСК.sh` |
| С телефона не открывается | IP LAN, не `127.0.0.1`; фаервол: порт 4173 |
| Нет LIVE на стакане | Не открывай `file://` — только HTTP через `./ЗАПУСК.sh` |
| Лог ошибок | `tail -n 50 .scalp-server.log` |

Параллельно с MUTE / другими проектами — ок: у sCalp порт **4173**, у MUTE обычно **8765**. Вторая сессия Termix:

```bash
cd ~/apps/SCALP   # или ~/SCALP
./ЗАПУСК.sh
```
