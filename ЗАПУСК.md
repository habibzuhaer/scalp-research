# sCalp — запуск

Коротко: как поднять всё без помощи агента.

Установка с нуля из zip: **[УСТАНОВКА.md](./УСТАНОВКА.md)** · архив: `~/Downloads/SCALP.zip`

## Рекомендуемый способ (HTML local)

```bash
cd .
./ЗАПУСК.sh
```

Откроется браузер → http://127.0.0.1:4173/

| URL | Что |
|-----|-----|
| http://127.0.0.1:4173/ | Панель запуска (hub) |
| http://127.0.0.1:4173/local/ | Терминал (стакан, график, скринер) |
| http://127.0.0.1:4173/docs/ | Документация |

Остановка:

```bash
./СТОП.sh
```

### Альтернативы тому же серверу

| Действие | Команда |
|----------|---------|
| Двойной клик | `sCalp.desktop` |
| GUI-кнопки (скрипты) | `python3 панель.py` или `sCalp-Panel.desktop` |
| Только сервер в терминале | `python3 local/serve.py` |
| Открыть раздел | `./open.sh terminal` · `docs` · `tv` · `hub` · `agents` · `api` |

Порт по умолчанию: `4173` (можно `SCALP_PORT=XXXX ./ЗАПУСК.sh`).

Логи: `.scalp-server.log` · PID: `.scalp-server.pid`

## React / Vite (`src/`)

Отдельный dev-сервер (не путать с `local/serve.py`):

```bash
cd .
npm install          # один раз
npm run dev          # откроет /react.html
```

Сборка:

```bash
npm run build
npm run preview
```

## Документация

Через уже запущенный local-сервер:

- http://127.0.0.1:4173/docs/
- или из хаба кнопки разделов

Файлы лежат в `docs/*.html` (можно открыть и через тот же `./ЗАПУСК.sh`).

---

## Что за что отвечает

| Проект / часть | Запуск | Нужен ли сервер |
|----------------|--------|-----------------|
| Hub / панель HTML | `./ЗАПУСК.sh` → `/` | да (`local/serve.py`) |
| Терминал агентов | `/local/` | да (WS/прокси бирж) |
| Docs | `/docs/` | желательно HTTP |
| TradingView redirect | `/local/tv-redirect.html` | желательно HTTP |
| React-приложение | `npm run dev` → `/react.html` | Vite |
| GUI-панель скриптов | `python3 панель.py` | сама вызывает `ЗАПУСК.sh` |

---

## Если «не открывается»

1. `./СТОП.sh` → `./ЗАПУСК.sh`
2. Проверить порт: `ss -tlnp | grep 4173`
3. Смотреть хвост лога: `tail -n 40 .scalp-server.log`
4. Не открывать `local/index.html` как `file://` для live-стакана — нужен HTTP.
