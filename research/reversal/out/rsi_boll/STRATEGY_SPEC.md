# Спека: RSI + Bollinger — сигналы и стратегия

Цель: по этой бумаге собрать **сигналы** (когда алерт) и **стратегию** (когда вход / стоп / тейк / выход).

Источник бэктеста: топ-волатильные Bybit, 5m/15m.  
Лучший каркас: **5m + стоп 1.2×ATR**.

---

## 1. Индикаторы (общие)

| Имя | Параметры | Зачем |
|-----|-----------|--------|
| RSI | period **14** | перепроданность / перекупленность |
| Bollinger | period **20**, std **2.0** | нижняя / верхняя граница |
| ATR | period **14** | размер стопа |

**«Вблизи полосы»** = цена касается или находится в зоне:

- к нижней: `low ≤ lower + 0.15 × (upper − lower)`  
  или `close ≤ lower + 0.15 × width`
- к верхней: `high ≥ upper − 0.15 × width`  
  или `close ≥ upper − 0.15 × width`

---

## 2. Сигнал ПОКУПКИ (long setup)

Срабатывает на закрытии бара `i`, если **подряд ≥ 5 баров** выполнено:

1. `RSI ≤ 27`
2. цена **вблизи нижней** Bollinger (см. выше)

**Вход в сделку:** не на этом баре, а на **open бара `i+1`**.

### Псевдокод сигнала

```
buy_bar[i] = RSI[i] <= 27 AND near_lower[i]

buy_streak[i] = buy_bar[i] ? buy_streak[i-1]+1 : 0

SIGNAL_BUY when:
  buy_streak[i] == 5          # только момент «набрали 5», не каждый бар дальше
  (или: buy_streak[i] >= 5 AND buy_streak[i-1] < 5)

ENTRY_PRICE = open[i+1]
ENTRY_TIME  = bar i+1 open
```

**Алерт «покупка»** можно слать уже на close бара, где streak стал = 5  
(«вход следующей свечой»).

---

## 3. Сигнал ПРОДАЖИ / выхода (из бэктеста почти не жил)

Изначально задумывалось:

```
sell_bar[i] = RSI[i] >= 82 AND near_upper[i]
sell_streak[i] >= 5  →  SIGNAL_SELL / закрыть остаток
```

На практике за окно сделки это почти **не встречается** (~0.05% баров).  
Для стратегии **не опираться** на это как на основной выход.

### Что использовать вместо «полного» sell

| Приоритет | Условие | Действие |
|-----------|---------|----------|
| 1 | цена ≤ стоп | закрыть **всё** |
| 2 | цена ≥ entry × 1.016 | закрыть **50%** (тейк1) |
| 3 | прошло N баров с входа | закрыть остаток по рынку |
| 4 *(опционально)* | RSI ≥ 70 **и** near_upper (1–2 бара, не 5) | закрыть остаток — для следующего теста |

**Тайм-стоп (из прогона):**

- 5m → **48 баров** (~4 часа)
- 15m → **32 бара** (~8 часов)

---

## 4. Стоп — как ставить

### Рекомендуемый (единственный плюсовый в прогоне)

```
STOP = ENTRY − 1.2 × ATR(14)   # ATR на сигнальном баре i
```

Типичный размер на 5m: **~0.9–1.5%** (медиана ~1%, среднее ~1.4%).  
На 15m тот же ATR часто даёт **~2.4%** — для 15m пока лучше не брать этот стоп как основной.

### Альтернативы (для сравнения / запасной режим)

| Режим | Формула | Комментарий |
|-------|---------|-------------|
| pct_1.2 | `ENTRY × 0.988` | простой, на 5m чуть хуже ATR |
| pct_1.6 | `ENTRY × 0.984` | симметрия с тейком 1.6% |
| struct | `min(low за 5 buy-баров) − 0.1×ATR` | «под зоной», нестабильнее |

**Правило риска:** если `STOP` дальше **12%** от входа или ближе **0.2%** — сигнал **пропуск** (шум / неадекватный ATR).

## 5. Тейки и размер позиции

```
SIZE_FULL = 1.0
TAKE1_PRICE = ENTRY × 1.016     # +1.6%

На касании TAKE1:
  закрыть 0.5 × SIZE_FULL
  остаток 0.5 держать до STOP / TIME / (опц. soft sell)

После частичного тейка стоп можно оставить как был
  или (следующий тест) перенести в BE = ENTRY
```

Из MFE-таблицы: на 5m ATR примерно **45%** сделок достигают +1.6% high’ом;  
p90 роста ~**6.5%**, иногда 10–25% на отдельных монетах — поэтому 50% на 1.6% логично, остаток «на хвост» + тайм.

---

## 6. Полный жизненный цикл сделки (стратегия)

```
1. SIGNAL_BUY (streak RSI≤27 + near lower == 5)
2. ENTRY @ open next
3. поставить STOP = entry - 1.2*ATR
4. поставить TAKE1 = entry * 1.016 на 50%
5. пока позиция открыта (по приоритету каждый бар):
     if low <= STOP        → close ALL, reason=stop
     if high >= TAKE1 and not taken → close 50%, mark partial
     if bars_held >= MAX   → close REST @ close, reason=time
6. конец
```

Один сигнал → одна позиция; после входа кулдаун **3 бара** (как в тесте), чтобы не набирать пачку.

## 7. Два слоя для кода SCALP

### A. Сигнальный агент (алерты)

События без исполнения:

| event | когда |
|-------|--------|
| `rsi_boll:buy_setup` | streak достиг 5 |
| `rsi_boll:take1_zone` | live цена ≥ entry×1.016 (если ведёте открытую) |
| `rsi_boll:stop_threat` | цена близко к стопу |
| `rsi_boll:time_exit` | дошли до MAX баров |

Поля в алерте: `symbol`, `tf`, `entry_hint`, `stop`, `take1`, `atr`, `rsi`, `bb_lo`.

### B. Стратегия / исполнитель

Тот же setup + ордера:

- entry market/limit на open следующей (или market сразу после сигнала — грубее)
- stop-market
- limit take 50% на +1.6%
- flatten по таймеру

## 8. На каком ТФ собирать сначала

| TF | Вердикт из прогона | Что собирать |
|----|--------------------|--------------|
| **5m** | sumR ≈ **+29** на ATR-стопе | **основная** стратегия + сигналы |
| **15m** | около нуля / минус на ATR | только сигналы «смотри» или стоп **−1.2% фикс**, не ATR |

Universe для старта: топ волатильных (как в `rsi_boll/universe` / research data), не весь рынок.

---

## 9. Чеклист «сигнал валиден»

- [ ] TF = 5m (для боевой логики)
- [ ] RSI(14) ≤ 27 пять баров подряд
- [ ] каждый из этих баров near lower BB
- [ ] streak **только что** стал 5 (не 6,7,8…)
- [ ] ATR есть, стоп 1.2×ATR в диапазоне 0.2%…12%
- [ ] нет открытой позиции / не в кулдауне

---

## 10. Что не путать

| Это | Не это |
|-----|--------|
| Buy = зона перепроданности у нижней полосы | не pin/engulf/sweep |
| Sell основной = стоп / тейк / тайм | не «RSI≥82 ×5» (слишком редко) |
| Тейк 1.6% = **половина** | не весь объём |
| Стоп от ATR | не обязательно равен 1.6% |

---

## 11. Готовая формула для карточки сигнала (пример)

```
BUY  AGIUSDT  5m
RSI≤27 ×5 @ lower BB
Entry ≈ 0.00610 (next open)
Stop  ≈ 0.00601  (−1.2×ATR ≈ −1.4%)
Take1 ≈ 0.00620  (+1.6% × 50%)
Rest  → time 48 bars / stop
```
